# Hitomatito

> Desarrollo Android con enfoque en rendimiento, integración de hardware y soluciones funcionales para casos reales.

Construyo productos que no solo funcionan: **funcionan bien, se mantienen bien y escalan con criterio técnico**.

## 👨‍💻 Perfil profesional

Soy desarrollador centrado en Android, especializado en construir aplicaciones robustas donde la estabilidad y la experiencia de uso son prioridad.  
Trabajo con una mentalidad orientada a producto: decisiones técnicas claras, código mantenible y resultados medibles.

## 🎯 Áreas de especialización

- **Android nativo** con Kotlin y Java
- **Bluetooth y comunicación con dispositivos externos**
- **Integración con hardware** en entornos exigentes
- **Herramientas de soporte y automatización** en Python, Rust y Dart
