# Hitomatito

> Android Developer enfocado en producto, rendimiento e integración con hardware real.

Diseño y construyo aplicaciones Android con una prioridad clara: **soluciones útiles, estables y técnicamente sólidas**.

## 👨‍💻 Perfil profesional

Desarrollador con enfoque práctico en Android nativo, especialmente en escenarios donde software y hardware deben trabajar sin fricción.  
Mi trabajo se centra en crear herramientas confiables para uso real, con arquitectura mantenible y atención al detalle técnico.

## 🔍 Enfoque técnico

- **Android nativo (Kotlin/Java)** con foco en rendimiento y estabilidad
- **Bluetooth Low Energy e integración de dispositivos externos**
- **Herramientas para diagnóstico, monitoreo y control del sistema**
- **Soporte multiplataforma de tooling** con Python, Rust y Dart

## 🧱 Proyectos principales

| Proyecto | Aporte técnico | Stack |
| --- | --- | --- |
| [AmWF](https://github.com/Hitomatito/AmWF) | Control de monitor mode en Android con detección de compatibilidad por chipset Qualcomm y validaciones en runtime | Kotlin / Android |
| [RedmagicCooler](https://github.com/Hitomatito/RedmagicCooler) | Control avanzado de cooler RedMagic 5 Pro por BLE con monitoreo térmico y automatización | Kotlin / Jetpack Compose |
| [HardWire](https://github.com/Hitomatito/HardWire) | Inspector de hardware Android vía ADB (USB/WiFi), snapshots y comparación de dispositivos | Kotlin / Compose / adblib |
| [gamepulse_hud](https://github.com/Hitomatito/gamepulse_hud) | HUD overlay para métricas en tiempo real (FPS, temperatura y memoria) orientado a gaming y debugging | Kotlin / Android |
| [Orbit](https://github.com/Hitomatito/Orbit) | Herramienta en Rust para auditar huellas de aplicaciones en Linux y desinstalación segura | Rust |
